# Kaisei Works 本番運用版

これは「自分に仕事を依頼してもらう」ためのサイトです。

## 仕組み

お客様
 ↓
サイトの依頼フォーム
 ↓
Google Apps Script
 ↓
Googleスプレッドシートに自動登録
 ↓
あなたのメールへ新規依頼通知

## 1. Googleスプレッドシートを作る

Googleスプレッドシートを新規作成してください。

シート名は何でもOKです。
Apps Script側が「依頼一覧」シートを自動作成します。

## 2. Apps Scriptを設定

スプレッドシートで、

「拡張機能」→「Apps Script」

を開きます。

既存コードを削除して、同梱の `Code.gs` を貼り付けます。

この行を自分のメールアドレスに変更します。

const OWNER_EMAIL = "ここに自分のメールアドレス";

保存します。

## 3. Webアプリとして公開

Apps Script右上の「デプロイ」
→「新しいデプロイ」
→種類「ウェブアプリ」

設定：
- 次のユーザーとして実行：自分
- アクセスできるユーザー：全員

「デプロイ」を押します。

発行された「ウェブアプリURL」をコピーします。

## 4. サイトと接続

`script.js` のこの部分：

const GAS_URL = "";

を、

const GAS_URL = "発行されたウェブアプリURL";

に変更します。

例：
const GAS_URL = "https://script.google.com/macros/s/XXXXXXXX/exec";

## 5. 公開

index.html / style.css / script.js をGitHub Pagesにアップロードします。

このサイトはサーバーを別途借りなくても、
GitHub Pages + Google Apps Script + Googleスプレッドシート
で受付システムを動かせます。

## 注意

- Google Apps Scriptは無料枠や仕様変更があります。
- 本格的な有料サービス運営では、迷惑送信対策・個人情報のプライバシーポリシー・利用規約・バックアップなどを追加してください。
- 現在のフォームは「依頼受付」に必要な情報をスプレッドシートへ登録する構成です。
- クレジットカード決済は含めていません。支払いを受け付ける場合は別途決済サービスを接続してください。
